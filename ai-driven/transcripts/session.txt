  **How it works:** every winning pattern is a list of 4 `[row, col]` cells. The list of patterns (`WIN_PATTERNS`) is built once when the module loads. Each call then only reads cells: for each pattern it takes the first cell, skips the pattern if that cell is empty, and otherwise checks that the other 3 cells match it. It returns on the first match, so when both players have a win, whichever pattern comes first in the list decides.

  ```ts
  for (const [[r0, c0], ...rest] of WIN_PATTERNS) {
    const first = board[r0][c0];
    if (first && rest.every(([r, c]) => board[r][c] === first)) return first;
  }
  return null;
  ```

  **The 19 patterns**

  | Condition | Count | Cells |
  |---|---|---|
  | Horizontal | 4 | row `r`: `(r,0) (r,1) (r,2) (r,3)` |

  **Avoiding repeated work**
  - **No per-call setup:** the patterns are worked out once, not on every call.
  - **No per-player pass:** the first cell of each pattern decides which player to compare against, so it checks X and O together.
  - **Early exits:**
    - an empty first cell skips the pattern after one read;
    - `every` stops at the first cell that doesn't match;
    - the loop stops at the first winning pattern.
  - **Worst case:** a board with no winner reads 76 cells (19 patterns × 4 cells).

  A further shortcut, returning early when a player has fewer than 4 pieces on the board, would cost an extra pass over every cell, so I didn't add it.
